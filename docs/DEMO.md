# Demo Fixtures

Demo mode provides deterministic local data for review, screenshots, and
testing without accounts or network access.

Fixtures:

1. Full-PPR redraft
2. Superflex dynasty startup
3. Superflex rookie draft
4. Keeper draft
5. Best ball
6. IDP
7. Completed draft
8. Traded rookie picks
9. Position run
10. Ambiguous identity match
11. Sleeper outage
12. Invalid OpenAI key
13. OpenAI quota error
14. OpenAI rate limit
15. Offline mode

Playback can pause, advance, reset, and change speed. Watchlist, strategy,
risk, hidden-player, and simulation controls remain interactive. Demo content
is fictional league/team context combined with public-style player metadata;
it never performs a provider write.
