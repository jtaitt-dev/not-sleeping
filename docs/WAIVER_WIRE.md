# Waiver Wire

The available pool is calculated from the full player index minus starters, benches, IR, taxi, and pending transaction adds; pending drops return to the provisional pool. Add/drop analysis protects never-drop starters, temporary injury holds, valuable handcuffs, and taxi/IR options.

FAAB output includes minimum, conservative, expected winning, aggressive, and maximum rational bids bounded by the user's actual remaining budget. Rolling, reverse-standings, daily custom, free-agent, and disabled systems receive appropriate actions instead of fake dollar advice. Claims remain manual in Sleeper.
