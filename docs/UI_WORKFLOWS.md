# UI Workflows

## First run

The user can enter a Sleeper username, configure an optional session key, or
enter Demo mode. Local functionality is immediately available.

## Live draft

The side panel detects Sleeper context, shows the active pick and turns until
the user's selection, recalculates recommendations after fixture or live pick
updates, and keeps roster need, position runs, recent picks, and available
players scannable. The user performs every pick in Sleeper.

## Research and planning

Players can be searched, watched, compared, or researched. Team, Dynasty,
Trade, Rankings, Data Center, and Usage keep deterministic context visible.
Research shows sources, confidence, freshness, conflicts, and unknown facts.

## Recovery

Provider errors stay localized. Cached and local tools remain available
offline. Settings can clear individual caches, export redacted diagnostics, or
reset extension-owned local data after confirmation.
