# Rookie Center

Rookie Center filters the verified player pool by experience, keeps NFL draft capital separate from fantasy draft capital, and supports rookie-only, supplemental, and continuation pools. Profiles can combine age, position, team, draft capital, production, athletic context, landing spot, role, and uncertainty when those fields are available.

Rookie recommendations use the same draft candidate engine as live and mock drafts. Missing data lowers confidence; it is not replaced by invented combine or college numbers. Rookie-pick trades use ranged future-pick value rather than an unknown exact slot.
