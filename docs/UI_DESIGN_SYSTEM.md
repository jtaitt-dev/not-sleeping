# UI Design System

Not Sleeping uses a dense, dark, Sleeper-adjacent visual language without
copying proprietary assets. The system uses neutral ink surfaces, restrained
teal status accents, consistent position colors, an eight-pixel spacing
rhythm, compact typography, and a single Lucide icon family.

Interactive controls provide visible focus, accessible names, disabled states,
and localized feedback. Player rows keep rank, identity, position, team, and
score visible at narrow widths while progressively revealing secondary data
at 480–600 px. Motion is limited to short state transitions and respects
`prefers-reduced-motion`.

Cached content remains visible while refreshing; loading skeletons preserve
layout. AI-derived values are visually separated from deterministic scores and
never dominate the live-draft hierarchy.
