# Start & Sit

Start & Sit translates Sleeper projections through the selected league scoring map, applies bounded availability/injury/evidence components, and solves the complete ordered roster with exact maximum-weight matching. It supports Superflex, multiple flexes, granular IDP, multi-position players, user locks, exclusions, empty slots, IR/taxi restrictions, and late-news pivots.

The workspace offers floor, balanced, and ceiling strategies. Every decision shows confidence, projected edge, key factors, pending information, freshness, sources, and the manual action required in Sleeper. Best Ball leagues show roster and replacement guidance instead of manual starter instructions. The extension cannot submit lineup changes.
