# IDP model

IDP values preserve granular eligibility and translate the league's exact tackle, assist, sack, tackle-for-loss, quarterback-hit, pass-defense, interception, forced-fumble, recovery, safety, touchdown, and bonus keys when raw statistics cover them. Role, snap opportunity, matchup, volatility, scoring scarcity, and dynasty age curves are separate bounded components. Unsupported scoring is surfaced rather than guessed.
