# AI Trades

Trade analysis is read-only. Local models own asset identity, roster-space
constraints, league market calibration, strategy, and value ranges. The AI
overlay may describe risk transfer, roster fit, and reversal conditions for
valid assets only.

No offer is created or sent. Cross-league state is keyed by league and subject;
a response for an older league/state hash is discarded. Provider disagreement
retains the deterministic baseline and is shown to the user.
